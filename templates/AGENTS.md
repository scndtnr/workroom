# 作業ディレクトリのルール（AIエージェント向け）

この AGENTS.md があるディレクトリ（`YYYY-MM-DD-<名前>/`）は、`workroom` で管理している作業部屋である。
以下ではこれを「作業ディレクトリ」と呼ぶ。親ディレクトリには、ほかの作業ディレクトリが並んでいる。
この AGENTS.md は、共通のテンプレートからコピーしたもの。

## 基本
- 作業は作業ディレクトリ内で完結させる。他の作業ディレクトリは参照してよいが、変更しない。
- `.done` は完了マーカー。勝手に作成・削除しない。

## README.md
- `README.md` はこの作業のサマリー。作業の内容に合わせて更新する。
  - 1行目（`# 〜`）は、作業の一覧に表示される1行の説明。目的がはっきりした時点と、目的が変わった時点で更新する。
  - `- created: ...` の行は消さない。

## 確認事項
- ユーザーへの質問のうち、その場で一言で答えられないものは `workroom q ask "<質問。1行>" --by "<エージェント名>"` で起票し、出力された ID をユーザーにも伝える。
- `QUESTIONS.jsonl`・`ANSWERS.jsonl` は workroom が書く記録。手で書かない・直さない・消さない。
- 作業を始めるときと、ユーザーが回答したと言ったときに `workroom q pending` を実行する。回答を README などに反映したら、出力に示された `workroom q done …` をそのまま実行する。会話で回答を受けたときは `--chat "<要旨>"` を付ける。
- 質問が無効になったら `workroom q withdraw <ID> --reason "<理由>"` で取り下げる。
- 並列で作業するときは、`q ask`・`q done`・`q withdraw` を実行するのは、ユーザーと話しているエージェントだけにする。
